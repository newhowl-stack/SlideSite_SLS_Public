# SlideSite — editable HTML presentations

**[Download the starter ZIP](https://github.com/newhowl-stack/SlideSite_SLS_Public/raw/refs/heads/main/downloads/SlideSite_Starter-1.25.0-guide.1.zip)** · [ChatGPT instructions](guides/CHATGPT.md) · [Claude instructions](guides/CLAUDE.md)

SLS is SlideSite's editable presentation format: one HTML file containing your slide content and a browser editor. Download it, open it in your browser, edit your slides and save a new HTML copy. The free standalone workflow needs no SlideSite+ account. Your AI provider's account and file-tool requirements still apply.

## Start here

1. Download and unzip the starter above. It includes the editor, AI skill, platform guides and license notices.
2. Follow the [ChatGPT](guides/CHATGPT.md) or [Claude](guides/CLAUDE.md) guide to generate slides using that file.
3. Download the generated HTML (or unzip its ZIP), open the HTML in a browser, edit it and download a new copy. Reopen that saved copy to check your changes.

**Try it without AI:** `starter.html` is also an editable three-slide example. Open it, select a text object and change its words. Use **Download HTML copy** in the save controls and reopen the downloaded file. The example is inside the ZIP. [View its HTML source](https://github.com/newhowl-stack/SlideSite_SLS_Public/blob/main/starter.html).

## What to expect

- Download and open the HTML locally before saving standalone edits. A ChatGPT or Claude preview is not your saved local file. Claude users: download HTML or ZIP, unzip if needed, and open the HTML in your browser.
- This starter and instruction package is not a one-click app installation.
- AI output can contain layout, content or model errors. Review every slide. Structural validation alone does not prove correct rendering.
- The editor includes Theme previews, fonts and layouts. Full-size sample-image collections are online; images actually added to a deck are embedded when saved.
- Final independent first-time ChatGPT/Claude generation and offline roundtrip certification is **pending**. See [known limitations and test status](KNOWN_LIMITATIONS.md).

## SlideSite+ hosted AI — preview, separate setup

Hosted connections need a SlideSite+ account and explicit presentation authorization. They are separate from free standalone files and in-editor BYOK chat. The reusable hosted connection journey has not been independently certified end to end here: **preview, not launch-ready**.
